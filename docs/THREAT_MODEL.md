# THREAT MODEL

## Amenazas cubiertas

- configuracion invalida;
- bundle adulterado;
- intentos de deriva operativa;
- operadores sin quorum;
- crecimiento no controlado del plano de control.

## Limites actuales

- sin hardware seguro no hay garantia absoluta contra acceso fisico total;
- sin enforcement real de kernel este bootstrap no ofrece aislamiento final;
- el formato de bundle es provisional;
- la firma de artefactos actual es un placeholder de integracion.
